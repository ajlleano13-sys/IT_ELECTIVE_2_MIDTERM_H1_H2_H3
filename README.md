# IT ELECTIVE 2 – MIDTERM H1_H2_H3

## Project Title

**Shopping Cart and Checkout System**

## Description

This project is an ASP.NET Core MVC web application developed as part of the IT Elective 2 Midterm Exam. It implements the required user stories for a shopping cart and checkout system.

The project demonstrates the use of ASP.NET Core MVC, C#, HTML, CSS, and other web development technologies to create a functional and organized web application.

## User Stories Implemented

### US-01 to US-04 – Shopping Cart

The following user stories were developed in the `feature/shopping-cart` branch:

* US-01 – Shopping Cart
* US-02 – Add items to cart
* US-03 – Update or manage cart items
* US-04 – Remove items from cart

### US-05 to US-06 – Checkout

The following user stories were developed in the `feature/checkout` branch:

* US-05 – Checkout
* US-06 – Complete the checkout process

This project uses separate branches to organize the development process:

* `main` – Main project branch

## How to Run the Project

1. Clone or download this repository.
2. Open the project solution in Visual Studio.
3. Make sure the required .NET SDK is installed.
4. Restore the project dependencies.
5. Build the solution.
6. Run the application using Visual Studio or the appropriate `dotnet run` command.
7. Open the displayed localhost URL in a web browser.

## Project Structure

The project follows the ASP.NET Core MVC architecture:

* **Models** – Contains the application's data models.
* **Views** – Contains the user interface and Razor pages.
* **Controllers** – Handles application requests and business logic.
* **wwwroot** – Contains CSS, JavaScript, images, and other static files.
